# Kredit aset

Perabot kantor 3D (`public/app/model/*.glb`) dikonversi dari "Office Pack" yang diberikan pemilik proyek (FBX/OBJ, dioptimalkan ke GLB, tekstur maks 512 px).
Paket itu tidak menyertakan file lisensi. Model low-poly semacam ini umumnya berasal dari Poly Pizza / Google Poly dengan lisensi CC0 atau CC-BY;
untuk CC-BY, cantumkan nama pembuat masing-masing model di sini sebelum dashboard dibagikan ke pihak luar.

Model yang dipakai: meja, kursi kantor, monitor, iMac, keyboard, sofa, sofa lebar, meja tamu, meja rapat bundar, tanaman (3 jenis), rak buku,
papan tulis, dispenser air, printer/copier, lemari arsip, lampu lantai, vending machine, tong sampah, tumpukan kertas, jam dinding, mug.
Model karakter berhak cipta di paket itu tidak dipakai. Avatar agent dibuat prosedural (tanpa aset luar).

three.js r170 (MIT) di `public/vendor/`.
